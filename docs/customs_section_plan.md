## Джерела даних

### Курси валют (РЕАЛІЗОВАНО — fetch_rates.py)
| Джерело | URL | Формат | Оновлення |
|---|---|---|---|
| НБУ офіційний | `bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json` | JSON | щодня 12:00 |
| Privat24 готівка | `api.privatbank.ua/p24api/pubinfo?exchange&json&coursid=11` | JSON | live |

### Митні новини (ТИЖДЕНЬ 2)
| Джерело | Тип | Як збирати |
|---|---|---|
| Держмитслужба customs.gov.ua | новини | BeautifulSoup парсинг |
| Кабмін kmu.gov.ua/news | постанови | RSS `kmu.gov.ua/rss/news` |
| МЗЕП me.gov.ua | накази | парсинг + дата-фільтр |
| Верховна Рада | законопроекти | API `api.rada.gov.ua` |

### Ціни-сировина (ТИЖДЕНЬ 3)

|---|---|---|
| Brent | EIA, World Bank | пакування, логістика |

| Целюлоза (NBSK) | RISI / Foex | паперова продукція |

## База даних — поки що JSON, потім MySQL

Стартуємо з JSON у `data/`:
- `data/rates.json` — курси (ТИЖДЕНЬ 1, ВЖЕ Є)
- `data/customs_news.json` — митні новини (ТИЖДЕНЬ 2)
- `data/commodity_prices.json` — сировина (ТИЖДЕНЬ 3)

Коли об'єми виростуть — мігруємо у MySQL (схема в архіві).
